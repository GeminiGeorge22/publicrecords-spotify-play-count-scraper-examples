# Spotify Play Count Scraper — exemplos

Contagens de reprodução de cada faixa em um link do Spotify (faixa, álbum, artista ou playlist), mais ouvintes mensais.

O Actor roda na **sua** conta da Apify (token de API ou OAuth). O uso é cobrado de você, no plano gratuito ou pago da Apify.

## Links
- [Página no Apify Store](https://apify.com/publicrecords/spotify-play-count-scraper)
- [Endpoint MCP da Apify](https://mcp.apify.com?tools=publicrecords/spotify-play-count-scraper)
- [Receitas n8n / Make / Zapier / Pipedream](https://github.com/GeminiGeorge22/publicrecords-mcp/tree/main/templates)

## Executar uma chamada síncrona

Defina `APIFY_TOKEN` com o seu próprio token da Apify. Não o envie no repositório.

```bash
export APIFY_TOKEN=YOUR_TOKEN
python3 examples/python/run.py
# node examples/javascript/run.js
# bash examples/curl/run.sh
```

Há exemplos em Python, JavaScript e curl em `examples/`. Autor: Public Records. Licença: MIT. Este repositório não usa GitHub Actions.
